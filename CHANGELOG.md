# Changelog

## 1.0.0

### Added
- Initial release of UI Consistency Extension for GSD
- 4 LLM-callable tools: scan, audit, generate, fix
- 1 slash command: `/ui-consistency` with subcommands
- 2 event hooks: session_start, before_agent_start
- Self-test tool for installation validation
- 14 automated tests covering structure, validation, and consistency
- install.sh with built-in test validation
- Workflow template with 6 phases (research, generate, scan, audit, fix, verify)
- 4 workflow files: generate-design-system, audit-and-fix, quick-scan, fix-only
- 5 reference docs: complexity-detection, design-system-format, legacy-classification, token-inheritance, wave-planning
